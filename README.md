#  Image Editor JS

A simple, browser-based image editor built with **HTML, CSS, and Vanilla JavaScript**.

The project focuses on practicing JavaScript fundamentals through real-world functionality such as image manipulation, filters, user interactions, and downloading the edited image.

##  Live Demo

**[Try Image Editor JS](https://amankr0028.github.io/Image-Editor-JS/)**

##  Features

*  Upload and preview an image
*  Apply image filters
*  Ad-just image properties
*  Reset edits
*  Download the edited image
*  Responsive interface
*  Works directly in the browser

##  Built With

* **HTML5** — Structure
* **CSS3** — Styling and responsive layout
* **JavaScript** — Image editing logic and interactions

##  What I Practiced

This project helped me strengthen my understanding of:

##  How to Run Locally
Clone the repository:

```bash
git clone https://github.com/amankr0028/Image-Editor-JS.git
```

Navigate into the project:

```bash
cd Image-Editor-JS
```

Then open `index.html` in your browser.

No backend or installation is required.

##  How It Works

1. Upload an image.
2. Use the available editing controls.
3. Preview the changes in real time.
4. Reset the image if needed.
5. Download the final result.

##  Project Goal

The main goal of this project was to move beyond basic JavaScript exercises and build something interactive that combines **logic, DOM manipulation, UI updates, and user interaction** into one project.
